For agents

Korean services, as tools your agent can call.

Gori turns Naver, Kakao, and more into typed tools with JSON Schemas and stable error codes. Your agent discovers them, calls them, and reads the results, with no glue code per provider.

The loop

How an agent uses Gori

01

Discover

Fetch the catalog. Every tool has an ID, a description, and a JSON Schema for its input.

GET /v1/tools
02

Offer

Pass the tools to your model as tool definitions. The schemas drop in unchanged.

kakao_search_places
03

Call

When the model picks a tool, send its arguments to Gori. Gori validates them and calls the provider.

POST /v1/tools/{id}/execute
04

Return

Hand the result back to the model: provider data, or an error code it can act on.

{ "data": … } { "error": "invalid_input" }
Connect

Two ways to connect your agent

Tool calling over HTTP

Coming soon

Works today with Claude, OpenAI, or any model with tool use. Map each catalog tool to a tool definition and forward calls to the execute route.

agent.js 
const { tools: catalog } = await (await fetch(`${GORI}/v1/tools`, { headers })).json();

const tools = catalog.map((tool) => betaTool({
  name: tool.id.replaceAll(".", "_"),
  description: tool.description,
  inputSchema: tool.inputSchema,
  run: async (input) => JSON.stringify(await (await fetch(
    `${GORI}/v1/tools/${tool.id}/execute`,
    { method: "POST", headers, body: JSON.stringify(input) },
  )).json()),
}));

const message = await client.beta.messages.toolRunner({
  model: "claude-opus-5-5", max_tokens: 16000, tools,
  messages: [{ role: "user", content: "Find three cafés in Seongsu-dong." }],
});

Recovery

Errors your model can act on

Gori answers with stable snake_case codes instead of raw provider errors, so the model can tell what went wrong and what to do next.

CodeWhat it means for the agent
invalid_inputThe arguments don't match the tool's schema. Fix them and call again.
unknown_toolThe tool ID isn't in the catalog. Re-read the tool list.
provider_not_configuredThe operator hasn't added credentials for this provider. Tell the user; retrying won't help.
provider_error (429)The provider's rate limit was reached. Wait, then retry.
provider_unavailableThe provider didn't respond in time. Retry later.

No agent?

It's a plain HTTP API too.

Agents are who Gori is built for, but scripts, backends, and cron jobs can call the same routes with any HTTP client.

curl 
curl localhost:3000/v1/tools/kakao.search_places/execute \
  -H "Authorization: Bearer $GORI_API_KEY" \
  -H 'Content-Type: application/json' -d '{"query":"성수 카페"}'
