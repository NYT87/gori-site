How agents connect to Gori{{icon.arrow}}
The name

고리 means a ring, a link.

go-ree · /ko.ɾi/

A small piece that joins things into something larger. An agent can decide what to do; acting on it means reaching a real service. Each integration is one more link between intent and action.

How it works

From clone to first tool call in three steps.

01

Deploy

Run the Node server with Docker Compose and PostgreSQL, or deploy the same core to Cloudflare Workers.

docker compose up --build -d
02

Add provider credentials

Use your NAVER API HUB application and Kakao REST API key. They stay on your infrastructure.

NAVER_CLIENT_ID=… KAKAO_REST_API_KEY=…
03

Call tools from your agent

Give your agent the catalog as tools and forward its calls to Gori. Inputs are validated against each tool's JSON Schema. MCP support is coming soon.

GET /v1/tools POST /v1/tools/{id}/execute
